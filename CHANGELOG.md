# Changelog

## v0.1 — 2026-10-19

First public release for Windows.

- Map builder, entity editor, asset browser and mod manager.
- Native compilation and direct play in the original engine.
- Custom props, textures, effects, sounds, entities, lighting and briefings.
- Doors, keycards, triggers, breakables, ramps and multiple layers.
- Display, control, camera and developer mods.
- Portable package with guided game-file import and local executable patching.

Original game files are required and are not included.
